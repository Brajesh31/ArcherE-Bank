# 📖 Glossary

| Term | Meaning |
|---|---|
| API | Interface exposed by the Express HTTP server |
| App Router | Next.js routing convention under app/ |
| Authentication | Verifying who the caller is |
| Authorization | Determining what an authenticated caller may do |
| Backend | Express process in server/server.js |
| Card-style record | Prototype visa_info row, not an issued card |
| CORS | Browser policy controlling cross-origin requests |
| CVV | Card verification value; must not be stored after authorization |
| DFD | Data Flow Diagram |
| Idempotency | Repeating an operation does not execute it twice |
| Ledger | Append-oriented record of balanced financial entries |
| Minor unit | Smallest unit of a currency |
| Migration | Versioned database schema change |
| Next.js | React framework used by the frontend |
| Request | Payment-request row in the prototype |
| Socket.IO | Realtime bidirectional communication library |
| Transaction | Database unit committed completely or rolled back |
| Trust boundary | Boundary where less-trusted input enters a trusted component |
| Transfer | Prototype activity row |
| UI | User Interface |
| WCAG | Web Content Accessibility Guidelines |

“Bank”, “Visa” and “card” refer to the prototype theme and schema names. They do not imply bank, card-network or payment-provider affiliation.
