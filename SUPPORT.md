## Asking for help

Use issue templates for reproducible bugs or scoped feature proposals. Include OS, Node/npm version, browser/MySQL version, command/route, sanitized error output and reproduction steps using synthetic data.

## Security

Do not publish vulnerability details in public issues. Follow [SECURITY.md](SECURITY.md).

## Safety

This is not a banking service. Never provide real financial credentials, personal identity information or payment data when asking for support.
